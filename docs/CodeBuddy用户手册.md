## 一、产品简介

CodeBuddy 是腾讯云推出的新一代 AI 智能编程编辑器，提供：

- **智能对话**：Ask / Craft / Plan 多模式对话式编程
- **代码补全**：贴合个人与团队习惯的智能补全
- **智能体（Agent）模式**：多步骤任务自动执行
- **Figma 转代码**、**MCP 工具接入**、**部署预览**等进阶能力
- 插件、IDE、CLI 三端覆盖全开发场景

---

## 二、系统要求

不满足以下要求的系统将**无法启动** CodeBuddy IDE。

| 操作系统    | 最低要求                                        |
| ------- | ------------------------------------------- |
| Windows | Windows 10 及以上（**不支持** Windows 7 / 8 / 8.1） |
| macOS   | macOS 11 (Big Sur) 及以上                      |

其他建议：

- 可用磁盘空间 ≥ 2 GB（含浏览器组件缓存）；
- 需要网络连接（登录认证、模型调用均需联网）。

## 三、下载与安装

### 1. 下载

1. 访问 CodeBuddy IDE 官网；
2. 单击右上角「**下载**」，系统将自动匹配当前设备的适配版本。

### 2. 安装

**macOS：**

- 将安装包拖拽到「应用程序（Applications）」文件夹中完成安装。

**Windows：**

1. 双击下载的 `.exe` 安装包开始安装；
2. 选择「**我同意此协议**」；
3. 选择安装位置，点击「**下一步**」直至完成；
4. 安装完成后关闭安装窗口。

## 四、账号配置

### 1. 登录

1. 打开 CodeBuddy IDE 客户端，单击「**登录**」；
2. 系统会**自动打开浏览器**跳转至登录页面；
3. 在登录弹窗中：
   - **必须勾选**《用户服务协议》与《隐私政策》；
   - 选择以下任一方式登录：

| 登录方式 | 说明               |
| ---- | ---------------- |
| 微信   | 扫码授权登录           |
| 手机号  | 手机号 + 验证码        |
| 邮箱   | 邮箱 + 验证码 / 密码    |
| SSO  | 单点登录，适用于企业版域账号场景 |

1. 浏览器页面显示「登录成功」后，**返回客户端**即可开始使用。

### 2. 账号管理

- **账户入口**：IDE 右上方「**账户**」按钮；
- 在该入口下可查看：**订阅（Plan）、积分（Credits）、用量（Usage）、账单（Billing）、发票（Invoice）**；
- **退出登录**：单击「账户」→「**退出登录**」。

### 3. 企业版说明

- 企业版用户通过 **SSO 域账号**登录，账号由企业管理员统一开通与分配；
- 具体操作参见企业版「登录指引」文档。

## 五、模型配置

CodeBuddy 的模型分为两类：**内置模型**（登录即用）与**自定义模型**（接入 OpenAI 兼容接口的第三方模型）。

### 1. 内置模型

1. 登录后，在**对话面板下方**找到**模型选择框**；
2. 直接在下拉列表中选择内置模型即可切换；
3. 不同模型档位消耗的积分不同，可在「账户 → 用量」中查看消耗明细。

### 2. 自定义模型（图形界面方式，推荐）

支持接入任何 **OpenAI 兼容接口**的模型服务（如腾讯云模型路由 CMR、DeepSeek、GLM、MiniMax 等）。

**配置步骤：**

1. 启动 CodeBuddy IDE；
2. 在**对话面板下方**单击**模型选择框** → 单击「**配置自定义模型**」；
3. 在「添加模型」页面，将**供应商设置为 `Custom`**；
4. 填写以下配置，单击「**保存**」：

| 配置项          | 填写说明                                                        |
| ------------ | ----------------------------------------------------------- |
| **Base URL** | OpenAI 兼容的对话接口地址，通常形如 `https://<服务商域名>/v1/chat/completions` |
| **API Key**  | 模型服务商签发的访问密钥（**创建后仅显示一次，务必立即保存**）                           |
| **模型名称**     | 当前 API Key 可调用的模型 ID 或意图路由名称（如 `ModelRouter/auto`）          |
| **高级设置**     | 按需勾选（上下文长度、温度等参数，视服务商支持情况）                                  |

1. 返回对话面板，打开模型选择框，在 **Custom Models** 分组中选择刚添加的模型即可使用。

**示例：接入腾讯云模型路由（CMR）**

| 配置项      | 配置值                                      |
| -------- | ---------------------------------------- |
| Base URL | `https://<用户域名>/v1/chat/completions`     |
| API Key  | 在「模型路由控制台」创建的 API Key                    |
| 模型名称     | `ModelRouter/auto`（按路由策略自动选择模型；也可填具体模型名） |

> 获取 CMR API Key：登录**模型路由控制台** → 创建模型路由 API Key → **关闭创建成功弹窗后将无法再次查看完整 Key**，请立即复制保存。

### 3. 自定义模型（配置文件方式，适用于 CodeBuddy Code 命令行）

编辑配置文件（不存在时新建）：

| 操作系统          | 配置文件路径                                  |
| ------------- | --------------------------------------- |
| Windows       | `C:\Users\<用户名>\.codebuddy\models.json` |
| macOS / Linux | `~/.codebuddy/models.json`              |

配置内容示例：

```json
{
  "models": [
    {
      "id": "ModelRouter/auto",
      "name": "Tencent Cloud CMR",
      "vendor": "Tencent Cloud",
      "apiKey": "<你的API Key>",
      "url": "https://<用户域名>/v1/chat/completions"
    }
  ]
}
```

字段说明：

| 字段       | 说明                                         |
| -------- | ------------------------------------------ |
| `id`     | 模型唯一标识，可为具体模型名或意图路由名（如 `ModelRouter/auto`） |
| `name`   | 模型在 CodeBuddy 中展示的名称，可自定义                  |
| `vendor` | 模型供应商                                      |
| `apiKey` | 服务商签发的 API Key                             |
| `url`    | OpenAI 兼容接口地址                              |

注意事项：

- 若 `models.json` 已存在，请将新模型**追加**到 `models` 数组中，不要覆盖原有配置；
- 命令行版首次启动时需确认信任工作目录、并选择登录站点（Chinese Site / International Site / Enterprise Domain / iOA）；
- 启动后输入 `/model` 并回车，可在模型列表中切换模型；
- 也支持通过环境变量传入密钥：`export CODEBUDDY_API_KEY="your-api-key-here"`（Windows PowerShell：`$env:CODEBUDDY_API_KEY="your-api-key-here"`）。

### 4. 模型选择建议

| 场景               | 建议                                             |
| ---------------- | ---------------------------------------------- |
| 日常对话 / 代码问答      | 内置默认模型即可，性价比高                                  |
| 复杂重构 / Agent 长任务 | 选用更强的旗舰模型档位                                    |
| 成本敏感             | 优先内置轻量模型；自定义模型走固定月费订阅（Coding Plan）替代按 Token 计费 |
| 团队统一管理           | 使用模型路由（CMR）统一出口，`ModelRouter/auto` 自动调度        |

## 六、常见问题（FAQ）

**Q1：登录后客户端一直转圈 / 未跳回？**  
确认浏览器已完成授权且勾选了协议；若仍失败，关闭客户端后重新点击「登录」。

**Q2：自定义模型保存后对话报错？**  
依次检查：Base URL 是否以 `/v1/chat/completions` 结尾且拼写正确；API Key 是否有效、是否与所选模型名称匹配；服务商是否限制了调用区域。

**Q3：API Key 忘记了怎么办？**  
在对应服务商控制台**重新创建**新 Key 并更新配置（旧 Key 建议作废），CodeBuddy 侧只改 Base URL 对应条目的 Key 即可。

**Q4：Windows 7 能否安装？**  
不能。最低要求 Windows 10。

**Q5：如何查看模型消耗了多少积分？**  
IDE 右上方「账户」→「用量 / 积分」页面查看。

## 七、安全注意事项

1. **妥善保管 API Key**：创建成功后仅显示一次，请立即复制保存；
2. **不要泄露 Key**：勿将包含真实 Key 的 `models.json`、Shell 配置、环境变量脚本提交到代码仓库；
3. 建议将含密钥的文件加入 `.gitignore`，或使用密钥管理服务；
4. 首次使用命令行版时，仅对**完全可信**的工作目录选择「信任」。
