01

在矩阵中的定位：横切的"执行编排层"

与现有产品区隔 + 协作

一句话定位

AI 智能层的"执行底座"——把 Code（写代码）、Work（管办公）等"单个能做什么"，升级为"把一大批 AI 任务自动、可监控、可恢复地批量跑完"。它不替代任何单点功能，而是让整张矩阵的 AI 能力"成规模落地"。

与谁区隔？（避免撞车）

≠ NexYawGate（枢流）：Gate 是企业业务流程编排 + 权限 + 审计（人/系统参与）；本项目是 AI Agent 任务的自动化批处理编排（机器自动跑）。一横一纵，绝不混说。

≠ NexYawCode / Work：它们是"做什么"；本项目是"把一堆'做什么'批量调度跑完、管好"。

与谁协作？（枢纽哲学三段）

承接母题"以枢纽之力"：Edge 接设备、Gate 接系统、Cast 接平台；本项目补上第四段——接 AI Agent / CLI，把批量任务编排跑完。它与 Cast 的"多源接入+归一化+编排+调度+看板"引擎同构，是面向开发者/自动化的"严肃版联播"。

关键洞察：单 Agent 任务"好用"，但成百上千任务"批量跑"就乱——断点、续跑、降级、原子回写、监控全是空白。本项目卖的不是"又一个 AI 工具"，而是 "AI 落地最后一公里的流水线"。这正是它作为命名候选 NexYawNav（自动领航一批任务） 的底层逻辑。

命名方案（严守红线：NexYaw + 独立英文实义词）

3 套，主推 1 套
主推 RECOMMENDED
NexYawNav
纽曜·领航
AI 智能层 · 枢纽蓝 词源：Nav = Navigation / 领航 与 Yaw（航向）同根

为什么是它：本项目"无头执行、自动把一批任务批量跑完"= AI 的自动领航；Nav（Navigation）最短、直觉，且呼应母词源 Yaw（航向自主调控）的航海家族，零解释成本。

中文"领航"直扣"自动带领一批 AI 任务抵达终点"，且呼应母口号"以枢纽之力"的带领感。虽未带"枢"字，但属双轨制中可接受的"功能/动作名"（参照 Code/Work/3D）。

子口号：枢纽驭批量，曜启领航新境
备选 A
NexYawHelm
纽曜·舵枢
AI 智能层 · 枢纽蓝 词源：Helm = 舵 / 掌舵

最贴"调度枢纽"意象：舵 = 掌舵调度，含"枢"字，与文枢/枢流/边枢形成"枢家族"呼应，家族感最强。

子口号：枢纽掌舵机，曜启调度新序
备选 B
NexYawFleet
纽曜·编队
AI 智能层 · 枢纽蓝 词源：Fleet = 舰队 / 一批

最直击"批量"语义：舰队 = 一批任务并行出海，呼应"批量"与"编排"；视觉易做成"多船协同"图标。

子口号：枢纽统编队，曜启跑批新生
命名红线提醒：英文一律 NexYaw 连写 + 首字母大写后缀（禁 Nex Yaw / nexyaw / NEXYAW）；中文保留间隔号"·"；子口号动词严格取自白名单 {启 / 筑 / 见}，骨架"枢纽+动词，曜+动词+三/四字宾语"不得改写。以上三方案均符合 v1.3 红线。
03

品牌基础：定位 / USP / 承诺 / 架构

所有渠道的上游依据

品牌定位

AI 批处理任务的自动领航枢纽：任务文件驱动 → 无头执行 → 原子回写 → 实时监控 → 随时终止/续跑。让 AI 从"单点好用"变为"规模可靠"。

强势 USP（差异化）

"AI 落地最后一公里，像流水线一样可靠。" 竞品多停在"单个对话好用"；本项目独占批量编排 + 断点续跑 + 降级不丢任务 + 结果可溯源四件套。

品牌承诺

每一批任务都可审计、可恢复、不丢结果：失败有降级、中断能续跑、结果原子落盘——把 AI 当生产力流水线，而非玩具。

品牌架构

母品牌 NexYaw 纽曜 统一背书；以"NexYaw + 后缀"挂靠，共享口号骨架与色板；视觉上复用超椭圆图标家族，层级色用枢纽蓝（与 Code/Work 同源）。

① 枢纽感

永远讲"批量、编排、贯通、成规模"，不讲孤立单任务。

② 工程严谨

口径精确、有出处、不超前承诺；失败透明（降级/续跑而非假装成功）。

③ 曜见新生

面向"AI 规模落地"的确定感，克制而不喧哗。

04

核心价值：冰山模型

水面下才是壁垒

用户看得见的是"批量跑完"，真正买单的是水面下"可靠、可恢复、不丢结果"的工程确定性。

06

五大识别系统（MI / BI / VI / EI / SI）

把意义快速浓缩

MI 理念识别

"让 AI 批量落地，像流水线一样可靠。" 不做单点玩具，做可编排的生产力底座。

BI 行为识别

工程严谨：可审计 / 原子写 / 不超前承诺 / 不丢任务；对失败透明（降级、续跑而非假装成功）；克制。

VI 视觉识别

枢纽蓝（AI 层）、超椭圆图标家族、复用 NexYaw 令牌；图标配方 #4F92D8→#2563A8→#1B4E7A。

EI 体验识别

本地、实时看板、可随时接管/终止、结果可溯源；"交给它，放心跑"的安全感。

SI 社会识别

开源/社区任务模板库；尊重 AI 额度与成本（不浪费、降级优先）；负责任的批处理——规模化使用 AI 也不失控。
