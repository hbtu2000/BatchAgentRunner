## UI 设计系统落地到 XAML 代码（续上）
- 触发：用户要求「按此规范修改页面代码」，把设计系统真正落地为 Avalonia 页面，使应用符合双主题 + 统一 token + 状态色 + 组件化。
- 关键架构决策（Avalonia 12 实测约束，踩坑点）：
  1. 全局无 key 的 `<Style>` / 隐式 `ControlTheme` 只能放在 `<Styles>` 文件、经 `App.axaml` 的 `Application.Styles → StyleInclude` 引入；**不能**放进 ResourceDictionary（否则报「Content of ResourceDictionary for argument ControlTheme」）。
  2. `ResourceInclude` 必须置于 `Application.Resources` 的 `MergedDictionaries` 内，直接作为 Resources 子项会报类型不匹配。
  3. **`Classes` 属性不接受 `{Binding}`**（XAML 编译器只接受字符串字面量）——状态着色无法用 `Classes={Binding ... Converter=...}`。改用 `StatusDotHelper` 附加属性把状态映射为 CSS 类（XAML 用 `conv:StatusDotHelper.TaskStatus/BatchStatusText/NavPage/NavActivePage`；需配套 `Get/Set` CLR 访问器，否则 XamlX 编不过）。
- 文件落地：
  - `Styles/AppStyles.xaml`（ResourceDictionary）：双主题 Token（Light/Dark）+ `Card` 关键 ControlTheme + `EqualsTextConverter` 实例 → 合并进 Application.Resources。
  - `Styles/GlobalStyles.axaml`（`<Styles>`）：隐式 `Button`/`TextBox` ControlTheme（全站自动应用，含 `:primary`/`:danger`）+ 状态点全局 `<Style>`（`Ellipse.st-*` / `Ellipse.batch-*` 按 class 着色，双主题自动切换、运行时切主题即时刷新）→ StyleInclude 进 Application.Styles。

  - `App.axaml`：`RequestedThemeVariant="Light"` + FluentTheme + StyleInclude(GlobalStyles) + Resources/MergedDictionaries/ResourceInclude(AppStyles)。

## 设计系统落地：修复启动崩溃（Styles 集合 vs ControlTheme）
- 现象：应用启动即 FATAL「ControlTheme (for Avalonia.Controls.Button) cannot be added to a Styles collection」，编译期 0 错误、运行时才炸
- 根因：**Avalonia 12 的 `Styles` 集合不允许放顶层 `ControlTheme`（含隐式无键的）**——`Styles.Add` 运行时校验直接抛 `InvalidOperationException`；XamlX 编译期不拦截
- 修复：`GlobalStyles.axaml` 中 Button/TextBox 的隐式 `ControlTheme` 改写为等价的普通全局 `<Style Selector="Button">` / `Button:pointerover` / `Button.primary`（Style 优先级高于 FluentTheme ControlTheme，覆盖正常）；状态点 `Ellipse.st-*`/`Ellipse.batch-*` 样式不变
- 允许的写法：资源字典内**带键** `ControlTheme`（如 AppStyles.xaml 的 `x:Key="Card"`，显式 `Theme="{StaticResource Card}"` 引用）
- 重建 0 错误（余 9 个测试侧 xUnit1031 警告为 P4 遗留）；文档 §9.2 已同步此约束

## 设计系统落地：修复第二个启动崩溃（CornerRadius token 类型）
- 现象：启动 FATAL「Unable to cast object of type 'System.Double' to type 'Avalonia.CornerRadius'」，发生在 MainWindow.!XamlIlPopulate
- 根因：AppStyles.xaml 把 RadiusSm/Md/Lg/Pill 定义为 `x:Double`，但 `CornerRadius` 属性经 DynamicResource 绑定时**不做类型转换**，Double 直接塞给 CornerRadius 即抛 InvalidCastException
- 修复：token 定义改为 `<CornerRadius x:Key="RadiusSm">6</CornerRadius>` 等（四处，仅被 CornerRadius 属性消费，无副作用）
- 验证：重建 0 错误；实际启动 exe 运行 8 秒日志无新 FATAL，窗口正常拉起
- 启动崩溃排查经验链：Avalonia 12 的 XAML 错误多数编译期不报、运行时才炸（Styles+ControlTheme、DynamicResource 类型不匹配均如此），每次改样式后必须实际启动验证
